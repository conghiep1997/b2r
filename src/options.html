Cài đặt nâng cao

Project profiles

Profiles belong to both server origins. Projects without a profile use global defaults.

Translation directions

These languages control content, independently of the interface language. Save with Save settings.

Report time logging

Configure daily hours and allocation. Load activities from your Redmine, select them, then save settings. Missing activities block logging.

Issue migration and matching

Quy tắc dùng khi chưa có mapping issue. Chỉ thay đổi khi quy ước project thay đổi; lưu bằng nút Lưu cấu hình.

Dùng {issueKey}, {summary}, {translatedSummary}. Ví dụ: [{issueKey}] {summary} / ({translatedSummary}).

Để trống để giữ cách nhận diện hiện tại. Nhập chuỗi phân cách chính xác, kể cả khoảng trắng; không dùng regex.

Tracker mapping

Enter the source issue type and preferred Redmine tracker names in order.

Migration due-date rules

Configure required dates and default working days by tracker. Zero days means no automatic date. Unlisted trackers have optional dates.

Project glossary

Use a Backlog project key (PROJECT) or redmine:project. Terms are encrypted and scoped to the configured workspace.

Migration recovery and issue mappings

Resume saved migrations in the configured workspace. Completed comments are skipped.
